Hello, and welcome! This is the first post on my personal site.

This site is built with [Next.js](https://nextjs.org) and deployed on [Vercel](https://vercel.com). Blog posts are plain Markdown files, so adding a new one is as simple as dropping a file into `content/posts/` and pushing to git.

In the future I plan to add some small interactive web games here too — stay tuned.
